Design de interface UI de formulário limpo para adicionar registros em aplicativo móvel, mockup vertical 9:16 de smartphone. O texto do cabeçalho superior diz 'Adicionar Transação' (Add Transaction) com um botão de voltar de seta para a esquerda simples e fino.
