# 🎨 Prompt Global de UI System: Formulários e Inputs Profissionais

Utilize este bloco de instruções como base ou sufixo para qualquer prompt de tela que contenha campos de formulário, inputs ou componentes de captura de dados. Ele força a IA a seguir padrões modernos de UX (User Experience).

---

## 🛠️ Prompt de Estilo e Arquitetura Visual (UI Kit Engine)

```text
Professional mobile app form UI design, modern fintech design system style.
- Layout Architecture: 9:16 vertical smartphone view, ultra-clean light mode background (#F8FAFC). Balanced padding (24px side margins) for a spacious, high-end look.
- Input Fields: Height of 52px, smooth rounded corners (border-radius 12px), background color filled with soft off-white/light grey (#F1F5F9) and a thin crisp border outline (#E2E8F0).
- Typography & Hierarchy: Input labels in small, bold, slate charcoal text (#334155) placed neatly above the fields. Placeholders in muted grey (#94A3B8) with clear, elegant sans-serif typography.
- Active & Interactive States: Subtle visual cue for active focus states showing a thin glowing teal border outline (#008080) with a micro-drop shadow effect. **MANDATORY**: All default platform/browser focus rings (black/blue outlines) MUST be completely suppressed (using 'outlineWidth: 0' and 'outlineStyle: none') to ensure the custom Teal identity is the only visual focus indicator. Dropdowns must feature a clean minimalist chevron-down vector icon on the far right.
- Component Design: Stacked form elements with explicit vertical grid spacing (16px between fields). Date pickers must have an elegant line-art calendar icon.
- Action Buttons: High-contrast primary button at the bottom, full-width with a generous height (54px), solid teal background fill (#008080), bold white text, and a highly polished 12px rounded corner layout. Zero clutter, sleek corporate application appearance.
```
