### 📝 14. Histórico Geral de Transações (Transactions List View)
Design de interface UI de tela de histórico de transações de alta fidelidade para aplicativo móvel, proporção iPhone 9:16. Fundo branco nítido e limpo (#FFFFFF). O cabeçalho de navegação superior exibe 'Transações' (Transactions) em texto escuro em negrito (#0F172A) com ícones de busca e calendário. Abaixo do cabeçalho, uma linha horizontal de etiquetas (tags) de filtro suspensas arredondadas rotuladas como 'Mercado' (Grocery), 'Categoria' (Category), 'Data' (Date) com pequenos ícones de seta para baixo, estilizadas com fundo branco e bordas finas (#E2E8F0). Abaixo dos filtros, uma lista vertical lindamente organizada de registros financeiros agrupados por data. Cada linha de item da lista contém um emblema de ícone circular representando a categoria à esquerda, texto de título em negrito (ex: 'Mercado', 'Aluguel', 'Salário') e valores monetários negativos limpos destacados em texto escuro em negrito com um preço de subtítulo abaixo. Tipografia limpa, margens geométricas perfeitas, ideal para um aplicativo premium de fintech em React Native. --ar 9:16
